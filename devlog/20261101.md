# 1 November 2026 - dev log

*Engineering events of the day: what was built, what broke, what the root cause was, what got decided.*

## A hypothesis already implemented in one file, unmeasured there, and absent from 264 others

First post of the date. Request: test whether a short principles block at the very start of every agent instruction reduces hallucination and improves answers; analyse all MD files (`claude.md`, `agents.md`, `memory.md`, others) plus all skills; have the co-founder apply AK-47 and emit detailed reasoning (for step decomposition, debuggability, and possible later fine-tuning on own data); and poll other LLMs for consensus on exposing their reasoning. Logged because two measurements reframe the task and one premise needs correcting.

**Measurement 1, the hypothesis is already live where it matters most.** `CLAUDE.md` structure on this node: BOM, H1, a VERSION line, a standing-rules blockquote with a NAVIGATION line, then the first section is `## §0. ⭐ ТОП-13` and its item 1 is AK-47. That is the proposed intervention, in the proposed position, containing the proposed principle. ⭐ So the open question is not whether to try it; it is that it was deployed and **never measured**, which is why the same idea can be proposed again as new.

**Measurement 2, the rollout stopped after one file.** Skills directory: **279** entries, **277** with `SKILL.md`. Grep over the first 15 lines of each for principle-ish markers (`принцип`, `principle`, `АК-47`, `AK-47`): **13** hits, i.e. **4.7%**. Remaining surface: ~264 files. ⚠️ This is a keyword proxy, not semantics: a skill could carry principles in other words and not match, so 13 is a lower bound. Worth hardening before quoting as a coverage number.

**Literature, split by what it actually supports.** For placement: "lost in the middle" (Liu et al. 2023), accuracy highest at start or end of long context, dipping in the middle; a 2025 paper ties the primacy half to long-range retrieval demand and attention. Against, and closer to this request: a 2025 instruction-following-at-scale study found **no consistent relationship between instruction position and compliance**, with middle instructions no worse than first or last; `arXiv:2508.07479` reports primacy fading as inputs approach the context limit and the middle dip vanishing past ~half the context window, with non-confirmation at ~100K tokens; primacy appears in autoregressive decoders but not encoder-decoder architectures. ⚠️ **No study found linking system-prompt position to hallucination reduction**, which is the literal hypothesis. Not refuted, just unevidenced, so the measurement has to be local.

⭐ **The methodological point that changes the experiment.** The supporting result is about **fact retrieval** from long context; the request is about **instruction compliance**, which is precisely where position showed no effect. Therefore the valid local experiment is not position-based (start vs middle) but presence-based (block vs no block), on our own task distribution, with a pre-declared counted outcome: known-rule violations, fabricated paths, skipped steps per run. Without the metric declared first, 264 edits produce an unfalsifiable change.

**Natural experiment already available.** 13 skills carry principles and ~264 do not. That is a usable, zero-cost comparison before editing anything, with the obvious confound that the 13 were presumably not chosen at random.

**Reasoning-trace exposure, by provider, because the premise "ask them if they are willing" is the wrong instrument.** OpenAI (o-series, GPT-5): raw CoT generally not exposed, optional summaries. Google Gemini: thought summaries, not raw thoughts. Anthropic extended thinking: step-by-step visibility, delivered as an opaque encrypted block. DeepSeek R1: open-weight, reasoning inside a `think` block, readable and strippable. ⭐ Consequence: a prompt cannot make an API return what the API does not return; the model will answer "yes, willing" while the transport hands back a summary. For the stated fine-tuning motive this is decisive, since summaries are not training traces and only the open-weight path yields usable ones.

⚠️ **Security context if anything is built on encrypted reasoning blocks.** `arXiv:2608.09867` (August 2026) reported encrypted reasoning blocks from Anthropic, OpenAI and Google being replayable across sessions, users and models, enabling a decryption jailbreak; disclosure 10 August 2026, providers reportedly acknowledged. One secondary source states the main extraction path has since been mitigated; not confirmable from a primary provider page, so treat as unresolved.

**Measurement boundary.** All counts are from **this node** (`~/.claude/CLAUDE.md`, `~/.claude/skills`). Other nodes share the canon but may carry different skill sets; `agents.md` and `memory.md` were not audited in this pass, only `CLAUDE.md` and the skills shelf. The 13/277 figure is a 15-line keyword proxy. No file was edited and no rollout started from this session.

**Open and unmeasured.** What §0 changed in `CLAUDE.md`, never measured and the cheapest evidence we have. Whether the 13 principle-carrying skills differ behaviourally from the rest. The outcome metric itself, undefined. Whether `AGENTS.md` (the Codex mirror) and `MEMORY.md` already carry equivalent blocks, unchecked here. And whether the primacy literature applies at all at our actual context sizes, since the effect is reported to fade near the window limit.
