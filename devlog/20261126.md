## Post 1: four parallel recall lanes "like Hindsight" - all four lanes already exist in `brain_ask.py` (dense on, PPR graph on since 2026-09-16, BM25 FTS5 off, temporal off); zero concurrency across the 4 search modules

**The ask** (FB 2026-11-26 17:10:07 UTC, `creation_time=1795713007`): re-listen to the Hindsight podcasts (agent memory, implementation, parallel search); make session start run several searches in parallel ("there are four kinds"); compare current mechanism vs Hindsight; take Hindsight as a canary and extend own search to run graph + vector + more in parallel, to get session context as fast as possible.

**Reference: Hindsight** (vectorize-io/hindsight; arXiv 2512.12818; ACL 2026 demo 27). Recall component TEMPR: four-way parallel retrieval = HNSW vector (pgvector) + BM25 + graph traversal/activation + temporal (filtering / temporal-graph parsing; naming differs across sources), fused with RRF, then neural re-rank. Reported LongMemEval 83.6%, LoCoMo 83.2% with a 20B open model (authors' numbers, unverified).

**Current state, measured 2026-11-27 on node MyOwnPC-Natalia** (`D:/OBSIDIAN/_imports/`, `brain_ask.py` 777 lines):

| lane | module | default | switch |
|---|---|---|---|
| dense (e5 / OpenAI index) | `brain_ask.py` | on | - |
| graph PPR file order + 1-hop expansion | `brain_graph.py` | PPR **on** since 2026-09-16 (`enabled()`); 1-hop only with `--graph`/`--ab` | `BRAIN_GRAPH_PPR=0` |
| lexical BM25 (SQLite FTS5), RRF with dense before rerank | `brain_lex.py` | **off** | `BRAIN_LEX_LANE=1` |

Fusion and rerank already exist: RRF dense+BM25 (`retrieve_candidates`), cross-encoder rerank (`mmarco-mMiniLMv2-L12-H384-v1`, swappable via `BRAIN_RERANKER`), `brain_graph.fuse_after_rerank` for PPR.

**Concurrency.** `grep -c -E "Thread|concurrent|asyncio"` over `brain_ask.py brain_lex.py brain_graph.py brain_temporal.py` → 0 / 0 / 0 / 0. Lanes are sequential. No `BRAIN_*` env set on this node (`env`, `~/.claude/machine.env`).

**BM25 lane evidence** (docstring of `retrieve_candidates`, gold-2026-09-16, 184 questions, BM25 alone, no dense, no rerank): Recall@12 title 0.950 · body 0.983 · bridge 0.404 · temporal 1.000, 25 ms/query.
