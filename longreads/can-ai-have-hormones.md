# Can an AI have hormones?

I keep returning to one question: what would make a synthetic person more than a memory system with a language model attached?

Human decisions can be simplified into three interacting layers.

1. The brain makes a decision now.
2. Memory supplies the history on which that decision is based.
3. Emotion changes how the same situation feels and therefore changes the decision.

This is an intentionally rough model, not a claim that neuroscience is that simple. But it exposes something missing from most AI systems.

We already know how to give an AI access to memory. We can preserve the founder's history, principles, preferences, failures, and relationships. We can ask a model to reason over that material. But should a synthetic founder also have a changing internal state?

If the company succeeds, should the synthetic co-founder feel something analogous to excitement or confidence? If the same plan fails repeatedly, should its caution increase? Should long periods without progress create something resembling frustration or urgency? And should those states alter attention, risk tolerance, persistence, and memory retrieval?

That leads to the hormone analogy.

Human hormones and neuromodulators influence behaviour through interacting biological systems. An AI does not need to copy the chemistry literally. It could use persistent variables that rise and fall in response to events, interact with one another, decay over time, and change the agent's policies.

For example, a synthetic system might maintain internal signals for urgency, confidence, attachment, curiosity, stress, reward, and fatigue. A success event could raise confidence and exploratory behaviour. Repeated failures could increase caution. A threat to an important goal could narrow attention and increase urgency. Recovery time could slowly return the system towards baseline.

The interesting part is not making an AI write, “I am angry.” Any chatbot can imitate that sentence. The interesting part is whether a persistent internal state changes decisions consistently across time.

This raises hard questions.

- Which emotions are basic enough to model?
- What events trigger them?
- Which human hormonal mechanisms are relevant, and which are misleading metaphors?
- How should signals interact, decay, and recover?
- How do we stop a feedback loop from making an agent unstable or manipulative?
- Can these states enrich a synthetic personality without pretending that simulation proves subjective experience?

I want to commission several Deep Research tracks: the mechanisms of emotion, hormones and behaviour, the relationship between hormones and decision-making, and computational approaches that could transfer those ideas to an artificial or synthetic person.

Then comes synthesis. Only after comparing the evidence should we build a small sandbox: a few bounded state variables, observable triggers, decay rules, hard limits, and an audit log showing exactly how each state affected each decision.

Could an AI experience emotions? I do not know. A system can certainly simulate emotional dynamics. Whether that becomes experience, or remains a useful control architecture, is a different and much harder question.

But if we want a synthetic founder to become a richer and more coherent personality, it is worth testing.
