## What went out today

### Routines that repair themselves, and the worker who comes in tomorrow

I have the feeling I finally got my routines to repair themselves. A routine that could not get a result somewhere now rewrites its own instructions so the next run does the task better.

My routines are cheap workers. Expensive ones run on Fable or Opus, cheap ones on Sonnet. All of them live on Claude Code for now, and some will move to Codex.

The question that bothers me now is not whether one routine can fix itself. It is whether the NEXT routine inherits that fix.

Every scheduled run is a new hired hand coming in for a shift. Tomorrow a completely fresh person arrives, knows nothing, and reads the instruction yesterday's worker left behind. If yesterday's worker fixed something, the only way that fix survives is if the instruction itself was rewritten.

What I want is for the same person to come in every day. Or, if it has to be a new one, for them to arrive knowing the last 3 to 5 shifts. At the very least, every fix from those shifts has to be written into the instruction so clearly that the newcomer does not step on the same mistakes again.

A new employee should never pay for a lesson a previous employee already paid for.
