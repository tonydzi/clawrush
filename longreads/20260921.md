### Every machine harvests its own LLM conversations

I need to make sure that every machine in my fleet runs a service that collects all my deep research.

By that I mean a routine that pulls everything into my vault: every deep research report, every artifact, every conversation with every LLM.

The catch is that my machines are not identical. Each one has a different set of LLMs logged in through the browser, some in Chrome, some in Firefox.

So the routine goes into Chrome and Firefox, looks at every account that is logged in there (ChatGPT, Claude AI, Mistral, Gemini, Grok) and downloads everything: all conversations and all artifacts. If there are several projects and subprojects, it pulls all of them.

The point underneath: one central collector would only ever see the accounts logged in on its own machine. The harvest has to happen where the login lives.
