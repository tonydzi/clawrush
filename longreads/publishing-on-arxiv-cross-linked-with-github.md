# Putting our work on arXiv, cross-linked with the open code on GitHub

Does anyone read papers on arxiv.org? It is focused on scientific work that researchers publish. I have another simple idea. I want to put up there both the things I wrote earlier (I have some very timely publications, ones that partly even called the trends in advance) and the things we are doing now. On our GitHub the actual code will live, all of our work. And we cross-link the two: from the paper a link to the code, from the code a link to the paper.

Why do I want this? Well, papers on arXiv get cited. And GitHub here serves as the proof that behind the pretty words there is real, working code you can take and check. Then one confirms the other. I will train my AI to write in an arXiv voice. We already have a voice for our Russian tech blogs, for Facebook, and now we add a separate, scientific voice for arXiv.
